# Dina Asis — Local Agent Prototype

نمونه آزمایشی اندروید برای دستیار عامل حسابداری با مدل GGUF و llama.cpp.

## رفتار
این برنامه چت‌بات نیست: درخواست کامل را می‌گیرد، وارد صف کارها می‌کند، با Qwen 3.8 2B یک برنامه JSON می‌سازد، ابزارهای آزمایشی را مرحله‌به‌مرحله اجرا می‌کند و گزارش کامل می‌دهد. خروجی توکن‌ها در UI استریم نمی‌شود؛ خروجی مدل پس از پایان تولید پردازش می‌شود.

## موتور
- Native llama.cpp از شاخه main ریپوی ai-chat-test کپی شده است.
- commit مبنا: 5e247a2124ce403b871c972daae1353c5187ec10.
- llama.cpp revision: 9871df5911a03a813518bcd623ee2eba91bf32aa.
- مدل GGUF از حافظه دستگاه انتخاب می‌شود؛ داخل APK نیست.
- اجرای CPU اجباری است: Native init با GPU غیرفعال و gpuLayers=0.
- ABI فقط arm64-v8a؛ Vulkan غیرفعال.

## اجرا
1. APK را بساز و نصب کن.
2. فایل Qwen 3.8 2B GGUF را انتخاب کن.
3. «بارگذاری CPU» را بزن.
4. درخواست مثل «برای آقای فلانی یک فاکتور فروش محصول A بساز و ارسال کن» را وارد کن.
5. آن را به صف اضافه کن و «اجرای صف» را بزن.
6. کار را انتخاب کن تا گزارش کامل و خروجی خام مدل را ببینی.

## ایمنی
مشتری و محصول داده ساختگی‌اند. ساخت فاکتور و ارسال فقط شبیه‌سازی می‌شوند. هیچ اتصال شبکه‌ای یا اتصال به پایگاه داده حسابداری، پیامک، ایمیل یا درگاه پرداخت وجود ندارد.

گزارش هر کار در حافظه خصوصی اپ در files/agent-reports ذخیره می‌شود.
